# Continue Freeze Frame

The 0.3.0 rescue-sequence implementation uses Godot 4.7.2 / Compatibility and preserves the existing cartoon courier and backgrounds. The active campaign is eight levels: four lessons, then Wrong Address, Fragile Delivery, Air Mail, and Express Route. The old campaign's progress remains in its original save section; the new campaign uses `rescue_sequences` and starts at one.

Five tools work together: umbrella and ramp redirect objects without removing danger, springs launch objects/courier, physical crates catch parcels and hold switches/plates, and eight-direction fans push objects/placed crates. Each tool kind has one editable slot within a per-level budget. Turn flips directional tools or rotates fan aim. Environmental switches latch, plates release their gates when weight leaves, bridges/perches break under direct parcel impact, and the final route includes a moving platform and conveyor. Completing Express Route requires landing on its platform.

`world.freeze()` captures the frozen scene. `rewind_plan()` rebuilds it at the same time with original hazard positions/velocities/timers and all placements/directions preserved, resetting mechanism and spring state. Results and timers are cancelled during navigation. Successful rescues save 30 Hz motion frames, impact focus, an event log and goals in versioned local Variant files (objects disabled). Replay is playback of recorded frames, not a resimulation. The latest successful replay per level is available from results and level select.

Read README.md for controls and commands. Source `/workspace/.cloud-setup/hypercasual/env.sh` in this cloud environment. Rendered tests use the existing Xorg display at `:99`. The matching engine, SDK, export templates, Java and debug signing key are already configured. Keep signing keys outside Git.

Verification reports and current screenshots are committed under `docs`. Headless tests cover all solutions, broken chains, ±12 px placement latitude, an alternate Wrong Address plan, cross-tool interactions, dangerous redirected parcels, live plates, retained rewind, touch, persistence and replay. Rendered tests play all four chains via real controls and repair Fragile Delivery with one added catcher after rewind. The debug APK is version 0.3.0 / code 3, ARM64, minimum API 24, target API 36, VIBRATE only, aligned and v2/v3 signed.
